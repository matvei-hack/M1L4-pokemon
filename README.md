покемон бот

привет. это мой бот с покемонами которого я сделал в телеграмме. можно создавать себе покемона кормить его тренеровать и драться с другими игроками или с дикими покемонами.

# что умеет бот

я использую PokeAPI чтобы доставать настоящих покемонов их картинки имена и характеристики.

вот все команды:
/go - создать своего покемона первый раз. может выпасть обычный покемон а может повезти и выпадет Волшебник или Боец у них особые способности
/mypokemon - посмотреть какой у тебя покемон щас
/info- тоже самое что mypokemon полная инфа о покемоне
/train - тренировать покемона получать опыт и повышать уровень
/feed- покормить покемона чтобы здоровье востанавливалось. но кормить можно не всегда надо ждать какое то время
/heal - сразу вылечить покемона
/rename - переименовать покемона как хочешь
/attack - атаковать другого игрока нужно ответить на его сообщение этой командой и будет бой
/battle - сразиться со случайным диким покемоном

про классы

у меня есть родительский класс Pokemon а от него наследуются два класса Wizard и Fighter.

Wizard волшебник у него больше здоровья и он может ставить магический щит во время боя. есть шанс уклонится от атаки.

Fighter боец у него больше силы и он может делать супер удар во время атаки. сила временно увеличивается.

это называется полиморфизм. когда у разных классов есть одинаковые методы например attack или info но работают они по разному.

 технологии

- Python
- pyTelegramBotAPI
- requests для запросов к API
- PokeAPI база данных покемонов
